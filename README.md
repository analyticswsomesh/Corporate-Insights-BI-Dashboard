# 📊 Corporate Insights & Hiring Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze corporate hiring trends, employee distribution, recruitment roles, and company insights across multiple organizations and locations.

---

## 🚀 Project Overview

https://github.com/user-attachments/assets/YOUR-VIDEO-LINK

The dashboard provides insights into:
- Company distribution across states
- Hiring activity and recruitment trends
- Employee role segmentation
- Workforce analytics
- Job type analysis
- Recruitment opportunity tracking
